# The Argos Game 🎄

A family Christmas price-guessing game, inspired by a long-running tradition:
cut-outs from the Argos catalogue with the prices blacked out — guess the price,
closest wins.

- **`index.html`** — the game. A single self-contained file (real Argos product
  photos and prices are baked in). Just open it in a browser, or host it anywhere static.
- **`project-argos.html`** — an early prototype of the multi-device,
  "join on your phone" version (TV / phone / iPad / desktop views).

## Play it
Open `index.html` in any modern browser. No install, no login.

## Host it free on GitHub Pages
1. Put these files in a GitHub repo (see steps in the chat).
2. In the repo: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   pick `main` / `root`, Save.
3. After a minute it's live at `https://<your-username>.github.io/<repo-name>/`.

Other one-click hosts that work the same way: Netlify, Vercel, Cloudflare Pages
(drag-and-drop the folder).
